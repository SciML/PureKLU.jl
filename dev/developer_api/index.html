Developer API

PureKLU's supported user API is the API reference together with the standard LinearAlgebra.Factorization operations it returns. The abstract type below is documented to make its implementation boundary explicit; it is not a downstream extension point.

PureKLU.AbstractKLUFactorization — Type
AbstractKLUFactorization{Tv, Ti} <: LinearAlgebra.Factorization{Tv}

Internal implementation supertype for PureKLU factorization objects.

Interface Rules

This is not an extension interface. Its methods depend on the storage and state invariants of KLUFactorization, so downstream packages must not subtype it. Use the public LinearAlgebra.Factorization interface instead: construct a factorization with klu, then use \, LinearAlgebra.ldiv!, size, eltype, nnz, nonzeros, adjoint, and transpose.
